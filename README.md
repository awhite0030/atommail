# AtomMail

Disposable email service built on Cloudflare Workers. No sign-up, no tracking, no persistence.

## Quick Start
1. Clone the repo
2. Deploy with wrangler or Vercel.

## Features
- Temporary inboxes
- Privacy focused
- Admin dashboard integration
